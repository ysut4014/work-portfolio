# 業務改善ポートフォリオ

現場の業務課題を整理し、Microsoft Power Platformを使った改善を提案しています。業務アプリの要件整理から、Power Appsの画面設計・実装、SharePointのデータ管理、Power Automateの処理フロー、動作検証まで担当してきました。

## 備品管理アプリ

Power Apps・SharePoint・Power Automateを組み合わせ、備品の予約・貸出・返却を管理する構成です。予約の重複チェック、Outlook予定表連携、返却リマインドを取り入れています。

**進捗**　運用中です。

[備品管理アプリの事例を読む](projects/equipment-management.md)

## 業務移動機の棚卸しアプリ

社員が自身の棚卸し対象を確認し、チェックボックスとボタン操作で対応完了を登録できるようにしました。

**進捗**　実装済みです。従来の手順と比較し、控えめな試算で約4,000分の作業時間削減を見込んでいます。

[業務移動機の棚卸しアプリの事例を読む](projects/mobile-device-inventory.md)

## 総務よろずAI

総務ポータルのFAQとPDF資料を根拠に回答するチャットを提案・実装しました。AIで解決できない質問は総務部へつなぎ、担当者が承認した回答をナレッジとして再利用できるようにしました。

**進捗**　検証環境でFAQ・PDFを根拠とした回答を確認済みです。総務部への問い合わせと回答管理の機能は実装済みです。

[総務よろずAIの事例を読む](projects/yorozu-ai.md)

## 社用車管理アプリ

総務が手入力していた車両・利用者・部署責任者の登録を、各部署で管理できるようにアプリ化しました。総務の車両担当者と詳細要件を詰め、画面設計全般とアプリ開発を担当しました。

**進捗**　開発完了・提出済み。運用開始時期を検討中です。

[社用車管理アプリの事例を読む](projects/vehicle-management.md)

## 請求書処理の効率化PoC

AI Builderで形式の異なる請求書の読み取りと伝票種別の判定を検証しました。複数の費目がまとまった特定様式では、明細の振り分けも検証しました。PDFのないルーティン請求も同じ請求管理簿で扱い、伝票作成・購買提出の期限をリストで管理する仕組みを設計しました。

**進捗**　請求書の読み取り・判定は検証完了、UIは調整中です。

[請求書処理の効率化PoCの事例を読む](projects/invoice-processing.md)
